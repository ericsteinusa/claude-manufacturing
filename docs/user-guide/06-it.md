# Information Technology (IT)

**Menu:** IT Technician menu (IT Tasks, Help Desk Tickets, Asset Management,
Network Status, Software Installations, Hardware Repairs, User Account
Management). Managers also see an **IT Manager** menu with Vendor Contracts,
IT Projects, and Security Management.

**Who can access it:** IT staff only.

## Dashboard (`/it/`)

Ticket status/priority/issue-type breakdown, asset status/type breakdown,
and a 6-month ticket trend.

## Help Desk Tickets (`/it/tickets/`)

Create a ticket (requester, department, issue type, description, priority,
assignee, submitted/due date); update any field, or just the status; filter
by status/priority/search.

## Assets (`/it/assets/`)

Register an asset (tag, type, make/model, serial number, assignee,
department, purchase date, warranty expiry, status) including full
depreciation fields (purchase price, salvage value, useful life, method,
cost center) — the system computes book value and accumulated depreciation
for you. Every reassignment or update is logged in that asset's history.

## Hardware Repairs (`/it/repairs/`)

Log a repair request (asset tag, problem, reporter, assignee, priority),
update status, and record the resolution.

## Software Installations (`/it/software/`)

Log a software install: asset tag, software name, version, vendor, install
date, installed-by, status.

## Licenses (`/it/licenses/`)

Create or edit a software license: product, vendor, key, type, seat
count/used, purchase/expiry date, cost, status.

## Network Devices (`/it/network/`)

Register or edit a network device: hostname, IP, MAC address, type,
manufacturer/model, location, status, last-seen.

## Tasks (`/it/tasks/`)

General IT tasks: name, type, description, assignee, department, priority,
scheduled/due date, with status updates.

## Incidents (`/it/incidents/`)

Log a security or system incident: title, severity, description, affected
systems, reported date, with status updates.
